# Step 06 — 가상 메모리 & 4단계 페이징 (VMM)

> 가상 주소를 PML4 → PDPT → PD → PT 4단계로 쪼개 따라가며, 원하는 가상 주소에 PMM 프레임을 붙인다.

## 목표

아무것도 없던 가상 주소 `0x400000000`(16GB)에 프레임을 매핑해 읽고 쓰기가 된다. 매핑을 풀고 접근하면 Page Fault 내용이 출력된다.

## 이 단계가 만드는 틀

- **`vmm_map_page(pml4, virt, phys, flags)`** — 커널에서 가장 많이 불리는 함수 중 하나. 힙(07), 유저 코드 · 스택(12·14), ELF 세그먼트(18)가 전부 이걸로 매핑
- **플래그 약속** — `VMM_PRESENT` · `VMM_WRITABLE` · `VMM_USER`. Step 12에서 USER 비트 처리가 보강된다
- **"1GB 위 주소는 내 마음대로"** — 0~1GB는 boot.s의 2MB 대형 페이지가 차지하므로, 동적 매핑은 그 위 주소를 쓴다 (힙 12GB, 유저 16GB 등)
- **Page Fault 진단** — CR2(폴트 주소)와 에러 코드 해석. 이후 메모리 버그의 80%는 이 메시지로 잡는다

## 만들 파일

| 파일 | 역할 |
|---|---|
| `mm/vmm.h` | 플래그 비트, 함수 선언 |
| `mm/vmm.c` | 인덱스 매크로, `vmm_get_pml4`(CR3 읽기), `vmm_map_page`, `vmm_unmap_page` |
| `kernel/idt.c` | 14번(#PF)일 때 CR2 · 에러 비트(not-present/protection, read/write, kernel/user) 출력 |
| `kernel/main.c` | `vmm_init` + 매핑 실습 |

읽는 순서: `mm/vmm.h` → `mm/vmm.c` (인덱스 매크로 → `vmm_map_page`) → `kernel/idt.c` (#PF)

## 핵심 개념

- **주소 쪼개기** (48비트 가상 주소):
  ```
  [47:39] PML4 인덱스 | [38:30] PDPT | [29:21] PD | [20:12] PT | [11:0] 페이지 안 오프셋
  ```
  각 9비트 = 512칸, 테이블 한 장 = 512 × 8바이트 = 4KB = 프레임 하나
- **엔트리** = 다음 테이블(또는 프레임)의 물리 주소 | 하위 12비트 플래그. `ENTRY_ADDR(e) = e & ~0xFFF`
- **없는 중간 테이블은 만든다** — PMM에서 프레임을 받아 0으로 채우고 연결. 아이덴티티 매핑이라 그 물리 주소를 바로 포인터로 써서 채울 수 있다
- **PS 비트(bit 7)**: PD 엔트리에 켜져 있으면 2MB 대형 페이지 — 그 아래 PT가 없다. 거기에 4KB 매핑을 끼워 넣으면 안 되므로 거절
- **TLB**: CPU는 변환 결과를 캐시한다. 매핑을 바꾸면 `invlpg` 로 그 주소 항목을 지워야 새 매핑이 보인다
- **CR3** = 현재 PML4의 물리 주소. 지금은 boot.s가 만든 PML4 하나를 모두가 공유 (프로세스별 CR3는 Step 20·22)

## 직접 만든다면

1. 인덱스 매크로 4개 + CR3 읽기
2. 이미 있는 매핑(예: `0x100000`)을 수동으로 따라가 물리 주소가 같은지 출력해 보기
3. `vmm_map_page`: 레벨마다 "없으면 만들고, 있으면 따라간다"
4. `invlpg` 추가, 16GB 주소에 매핑 → 쓰기 → 읽기
5. `vmm_unmap_page` 후 접근 → #PF 메시지 다듬기

## 확인

- `[test] virt=0x400000000 -> phys=0x... value=0xc0ffee`
- 주석을 풀면 `[vmm] Page Fault: addr=0x400000000 err=0x0 (not-present read kernel)` 후 패닉

## 자주 막히는 곳

| 증상 | 원인 |
|---|---|
| 매핑했는데 접근 시 Page Fault | 마지막 엔트리에 PRESENT 누락 / `invlpg` 누락 |
| `2MB large page exists` 에러 | 1GB 아래 주소에 매핑하려 함 |
| 엉뚱한 메모리가 덮어써짐 | 새 테이블 프레임을 0으로 안 채워 쓰레기 엔트리가 PRESENT로 보임 |
